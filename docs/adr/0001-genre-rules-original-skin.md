# Genre rules, original skin

The game's rules and mechanics are a deliberate homage to the Chip's Challenge genre and should feel instantly familiar to its players, but everything you see or hear is original: name, characters, story, art, sound, and every Level. Rules and Level files therefore use plain functional names (Collectible, Gate, Flippers), and the themed skin is applied only in the rendering layer, so the skin can change without touching rules or Levels.

## Consequences

- Never copy the original game's names, characters, tile art, music, or Levels, even as placeholders. This keeps a future public release clear.
- A rule-level name in code or Level files must never be a skin name.
