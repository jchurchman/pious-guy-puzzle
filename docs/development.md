# Development

Planned commands; the scaffold ticket creates them. Run from the repository root:

```bash
npm i           # install dependencies
npm run dev     # dev server; add ?level=N to the URL to jump to Level N (development only)
npm test        # run every test once
npm run build   # production build into dist/; needs approval
```
